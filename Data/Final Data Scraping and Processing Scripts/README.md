# Final Data Scraping and Processing Scripts

Scrapers, processing scripts, and the four final datasets for a **Maithili & Bhojpuri
news-article corpus**. Each dataset is scraped from one source website, optionally enriched
with headlines, and cleaned.

## Datasets → source → scraper

| Dataset (`datasets/`) | Source site | Language | Rows | Generated by |
|---|---|---|---|---|
| `bhojpuri-1.csv` | khabarbhojpuri.com | Bhojpuri | 4,982 | `scrapers/Bhojpuri/khabar_bhojpuri_Scraper.py` → `fetch_headlines_bhojpuri.py` |
| `bhojpuri-2.csv` | anjoria.com | Bhojpuri | 10,072 | `scrapers/Bhojpuri/bhojpuri_scrapper_3.py` |
| `maithili-1.csv` | maithilijindabaad.com | Maithili | 5,573 | `scrapers/Maithili/maithili_scraper.py` → `fetch_headlines.py` |
| `maithili-2.csv` | esamaad.com | Maithili | 2,997 | `scrapers/Maithili/scraper.py` |

## Scrapers (`scrapers/`)

**Bhojpuri**
- `khabar_bhojpuri_Scraper.py` — khabarbhojpuri.com (Selenium). → bhojpuri-1
- `fetch_headlines_bhojpuri.py` — adds the `headline` column to the khabarbhojpuri output.
- `bhojpuri_scrapper_3.py` — anjoria.com (Selenium, sitemap + pagination). → bhojpuri-2

**Maithili**
- `scraper.py` — esamaad.com (sitemap, requests + BeautifulSoup). → maithili-2
- `maithili_scraper.py` — maithilijindabaad.com (paginated, Devanagari cleaning). → maithili-1
- `fetch_headlines.py` — adds the `article_headline` column to the maithilijindabaad output.

## Processing (`processing/`)
- `validate_dataset.py` — quality report (low-Devanagari, preamble remnants, duplicates, short rows).
- `clean_dataset.py` — applies those fixes (drop / re-strip / deduplicate).
- `diagnose_bhojpuri.py` — Bhojpuri scraper output diagnostics.

## Pipeline
```
scrape ──► fetch headlines (where applicable) ──► validate / clean ──► datasets/*.csv
```

Row counts are true CSV records (Maithili text has embedded newlines, so `wc -l` over-counts).
